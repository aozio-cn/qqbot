# QQBot AI 管理平台

> 当前版本：**v20261004**

一键接入自定义 AI 模型的 QQ 官方机器人管理平台，支持多机器人统一管理、群聊私聊上下文记忆、指令系统与定时任务，并带可视化安装向导与后台管理面板。

## 功能特性

- 支持 QQ 官方机器人一键接入（OpenAPI v2）
- 自定义 AI 模型（兼容 OpenAI 格式 API）
- 群聊 + 私聊上下文记忆（群聊中识别多用户，私聊时延续群聊对话）
- 多机器人统一管理：添加 / 编辑 / 删除、连接状态、休眠唤醒
- 指令系统：菜单、任务开关、入群欢迎、撤回、禁言、天气、抽签、订阅等
- 定时任务：整点报时、入群欢迎 / 退群提示
- 自动 OpenID 抓取：后台生成校验码，群里 @ 机器人发送即可识别
- 黑白简约管理后台，兼容移动端
- 可视化安装向导，小白也能快速配置

#### 修复的 Bug

1. **机器人自己发送的消息被误识别为"其他机器人"**
   修正消息作者识别逻辑，使机器人能正确区分"自己发送"与"其他机器人发送"，避免误标。

2. **群内其他机器人的消息被误显示为虚拟用户**
   修复其他机器人被当成真人用户（显示为"用户XXX"）的问题，现正确识别为机器人角色；历史记录已批量校正。

3. **模型回复带出消息前缀**
   模型会模仿历史消息格式，在回复里带出"机器人·（名字）：""用户·XX："等前缀，污染群消息。已通过回复前缀过滤 + 历史记录清洗根治。

4. **后台聊天记录按钮溢出屏幕**
   聊天详情卡片的"关闭 / 删除"按钮在窄屏下横向溢出浏览器，改为可换行往下排列，不再往右挤。

5. **引用（回复）消息无法识别**
   修复消息事件中引用字段的解析，同时适配"全量消息模式"与"仅艾特模式"两种事件，并补全本地消息 ID 记录，使引用内容可被正确识别。

6. **机器人之间互相接话形成连续对话**
   通过提示词约束 + 选择性回复机制，避免同一群内多台机器人互相聊起来、刷屏。

#### 新增功能

- **选择性回复机制（`[no]` / `[yes]` 协议）**
  机器人可自主判断是否回复：对其他机器人的消息默认只读不回复；`[no]` 表示不发送且不写入会话记录，`[yes]内容` 表示发送指定内容。
- **虚拟昵称体系**
  真人用户显示为"用户 + openid 前 6 位"，机器人显示真实名或 `other.bot`；群消息携带群 ID，AI 能感知群内成员关系。
- **艾特识别与翻译**
  识别"谁艾特了机器人"，并将消息中的 `@openid` 翻译为可读昵称。
- **后台聊天记录三色区分**
  真人（蓝）、本机机器人（绿）、其他机器人（浅粉）用不同徽章颜色区分。
- **删除聊天记录**
  后台可删除单条聊天记录，删除前弹窗确认，防止误删。
- **模型输出清洗**
  回复发送前自动过滤可能模仿出的称呼 / 名称前缀，保证群里发出的是干净内容。

#### 优化

- **系统提示词重构**
  改为结构化的英文单段规则，明确安全边界、选择性回复、不与机器人互聊、回复不加称呼和名称等约束，提升对话质量。
- **消息上下文构造优化**
  按角色（本机 / 其他机器人 / 真人）规范化发给模型的历史消息，避免模型混淆身份、误仿格式。
- **引用识别查源优化**
  优先从实际对话记录中按消息 ID 定位被引用内容，兼顾全量与仅艾特两种事件模式的字段差异。

## 快速部署

### 方法一：宝塔面板部署

1. 在宝塔面板安装 Node.js 版本管理器（推荐 Node 16+）
2. 上传项目文件到网站目录
3. 在项目目录执行 `npm install` 安装依赖
4. 在宝塔面板「软件商店」安装「PM2管理器」
5. 在 PM2 管理器中添加项目：启动文件 `server.js`、项目目录为项目根目录
6. 访问 `http://服务器IP:3000/install.html` 完成安装
7. 在宝塔「网站」中添加反向代理，将域名指向 `127.0.0.1:3000`

### 方法二：命令行部署

```bash
# 安装依赖
npm install
# 启动（开发测试）
node server.js
# 生产环境推荐使用 PM2
npm install -g pm2
pm2 start server.js --name qqbot
pm2 save
pm2 startup
```

### 方法三：Systemd 服务（推荐）

创建 `/etc/systemd/system/qqbot.service`：

```ini
[Unit]
Description=QQBot AI Management Platform
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/qqbot
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production
Environment=PORT=3000

[Install]
WantedBy=multi-user.target
```

然后：

```bash
systemctl daemon-reload
systemctl enable qqbot
systemctl start qqbot
```

## 常见问题

**Q: 安装后忘记管理员密码怎么办？**
A: 删除 `data/config.json`，重新访问安装页面即可重新配置。

**Q: 机器人连接失败？**
A: 检查 AppID/AppSecret 是否正确，确认机器人已在 QQ 开放平台发布上线，检查服务器网络是否能访问 QQ 接口。

**Q: AI 模型回复很慢？**
A: 检查上游 API 的响应速度，可在后台更换更快的模型或 API 地址。

**Q: 如何更新版本？**
A: 备份 `data/` 和 `chat history/` 目录，替换项目文件后重启服务即可，数据不会丢失。
